# Popular Sanskrit Shloka Classes — Showcase Website

A premium single-page demo website for **Popular Sanskrit Shloka Classes**,
Osmanpura, Chhatrapati Sambhajinagar (Aurangabad), Maharashtra.

> Ancient Wisdom. Modern Living.

## Tech Stack

- **React 19 + Vite** — fast, modern build
- **Tailwind CSS v4** — custom design tokens (forest green, saffron, muted gold, parchment)
- **Framer Motion** — slow, elegant reveal / parallax / floating animations (reduced-motion aware)
- **Lucide Icons** — thin-stroke iconography
- **Fonts** — Cormorant Garamond (display), Inter (body), Noto Serif Devanagari (shlokas)

All artwork (temple sunrise scene, gallery tiles, map) is **hand-built layered SVG** — no stock images.

## Run Locally

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # production build → dist/
```
